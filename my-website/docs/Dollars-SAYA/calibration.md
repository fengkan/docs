# 校准

## 校准的作用

如果设备存在一定的倾斜角度（如前倾或后仰），可能导致虚拟形象的身体姿态出现偏差。通过校准，可以改善这一现象。

同时，由于每个人的面部特征存在基准偏差，也会影响表情的还原效果，进行校准可以更准确地识别动态表情变化。

在全身捕捉模式下，校准还会将虚拟形象移动到原点，方便与场景进行位置对齐。

## 校准方法

点击程序下方的按钮开始进行校准。

![](../img/2026_08_19_10_48_22-SAYA.png)

校准时，请放松身体和表情，双手自然下垂，目视前方。

在全身捕捉模式下，请自然站立在动捕范围的中央，并确保从头到脚完整处于画面中。

倒计时结束，出现“校准完成”的提示之后，即可进行正常动捕。

校准过程中，您可以点击同一按钮，取消校准。
