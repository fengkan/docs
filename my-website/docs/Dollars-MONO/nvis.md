# 激活 NVIS 模块

如果您已经购买了 MONO 授权，由于 MONO 离线运行，系统无法在您购买 NVIS 授权后自动获取相关授权信息。

此时，您可以点击 MONO 左下角的登出按钮，

![](../img/2026-10-2920-04-13-587.mp4_20261029_200427.914.jpg)

在弹出的对话框中确认登出。

![](../img/2026-10-2920-04-13-587.mp4_20261029_200431.004.jpg)

下次登入时，MONO 将会获取您最新的 NVIS 授权信息。
