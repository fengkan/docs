# 校准

## 校准的作用

如果摄像头存在一定的倾斜角度（如前倾或后仰），可能导致虚拟形象的身体姿态出现偏差。通过校准，可以抵消摄像头的倾斜。

校准还会将人物移动到原点，方便与场景进行位置对齐。

同时，由于每个人的面部特征存在基准偏差，也会影响表情的还原效果，进行校准可以更准确地识别动态表情变化。

## 校准方法

点击 **校准** 按钮或按下快捷键 **C** 开始校准。

![](../img/2026_10_29_19_59_00-Dollars_MONO.png)

校准时，请坐着或站立在动捕区域的原点，放松身体和表情，双手自然下垂，目视前方。

倒计时结束，出现“校准完成”的提示之后，即可进行正常动捕。

## 画面中无人时的校准

如果校准时画面中没有人，MONO 会根据画面内容抵消摄像头的倾斜。此时不会对人物位置和面部表情进行校准。

## 无法校准的情况

如果画面中没有人，并且场景为单一颜色（如绿幕），MONO 无法从画面中判断摄像头的倾斜，校准将无法完成。此时请站入画面后再进行校准。
