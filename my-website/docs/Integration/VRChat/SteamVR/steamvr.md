# 启动与校准

## 启动

1. 打开 Dollars MONO 和 Bridge，再启动 SteamVR。
2. 从 Steam 启动 VRChat，并选择 SteamVR 模式。
3. 在 VRChat 设置的 Tracking & IK 中，将 User Real Height 设为 5' 11"（1.80 m）。

建议先使用 6 点追踪（腰部和双脚）。如有需要，可在 Bridge 的驱动设置中启用胸部、双肘和双膝追踪点。

## 全身校准

1. 在 Bridge 中点击「鼠标键盘控制」，按 Q 打开快捷菜单，再点击「Calibrate FBT」。
2. 按 Esc 退出鼠标键盘控制，让头部和双手恢复为动捕控制。
3. 点击 Bridge 中的「校准 FBT」，并在 10 秒内站直，将双手向两侧伸展。倒计时结束后，Bridge 会自动同时按下左右手柄的扳机，完成校准。
