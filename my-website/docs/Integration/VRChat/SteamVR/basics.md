# VRChat 基本使用

:::info 注意
使用前，请先按照 [SteamVR 开始使用](/steamvr-getstarted) 安装道乐师 SteamVR 驱动，并在道乐师产品中启用 SteamVR 推送。
:::

:::warning 警告
由于 VRChat 的交互是为 VR 设备设计的，而我们在没有 VR 设备的情况下操作，体验可能不够流畅，敬请谅解。

我们会持续改进操作体验。
:::

您可以使用鼠标和键盘控制 Avatar 移动和转身，也可以更换 Avatar 或前往其他 World。

## 移动与转身

使用以下按键控制 Avatar 移动和转身。

| 按键 | 说明 |
| --- | --- |
| W | 前进 |
| S | 后退 |
| A | 向左平移 |
| D | 向右平移 |
| 逗号（,） | 向左转身 |
| 句号（.） | 向右转身 |

## 菜单

在 Bridge 中点击「鼠标键盘控制」后，可以通过以下方式打开 VRChat 的菜单。

| 菜单 | 打开方法 |
| --- | --- |
| 快捷菜单（Quick Menu） | 按 Q 打开或关闭 |
| 动作菜单（Action Menu） | 按 E 打开或关闭 |
| 主菜单（Main Menu） | 通过快捷菜单进入 |

菜单打开后，移动鼠标对准菜单项，点击鼠标左键即可选择。操作完成后，按 Esc 退出鼠标键盘控制，头部和双手将恢复由动捕数据控制。

### 主菜单

打开快捷菜单后，点击右下角的设置按钮，再点击右上方的放大按钮，即可进入主菜单。

此外，点击快捷菜单首页（Launch Pad）上的 **Avatars**、**Worlds** 等按钮，也可以直接进入主菜单的对应页面。

## 选择 Avatar

1. 在 Bridge 中点击「鼠标键盘控制」，然后按 Q 打开快捷菜单。
2. 从快捷菜单打开主菜单，进入 **Avatars** 页面。
3. 选择想要使用的 Avatar 并应用。

<video controls width="100%">
  <source src="/vrchat-select-avatar.mp4"/>
</video>

## 选择 World

1. 在 Bridge 中点击「鼠标键盘控制」，然后按 Q 打开快捷菜单。
2. 从快捷菜单打开主菜单，进入 **Worlds** 页面。
3. 选择想要前往的 World 并进入。

## 常见问题

### 按 Q 或 E 后菜单没有出现

可能是 SteamVR 的系统菜单处于打开状态。系统菜单只显示在 VR View 中，下方视频右侧的窗口即为 VR View。

请在 Bridge 中点击手柄上的系统按钮关闭系统菜单，然后再按 Q 或 E，即可正常打开快捷菜单或动作菜单。

<video controls width="100%">
  <source src="/vrchat-faq-system-menu.mp4"/>
</video>

### 快捷菜单出现后又消失了

一般是由于之前的操作没有关闭菜单，菜单仍附着在 Avatar 的手上。请在鼠标键盘控制中向下移动鼠标，让视角向下，以查看 Avatar 手上是否还显示菜单。

如果有，请在 Bridge 中点击手柄上的菜单按钮将其关闭，可能需要点击多次。关闭后即可再次正常打开快捷菜单。
