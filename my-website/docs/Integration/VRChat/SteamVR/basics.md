# VRChat 基本使用

:::info 注意
目前支持 Dollars MONO。使用前，请先按照 [SteamVR](/steamvr-getstarted) 一节安装驱动，并在 MONO 中启用 SteamVR。
:::

本页介绍通过 SteamVR 使用 VRChat 时，如何移动和转身，以及如何选择 Avatar 和 World。

## 移动与转身

动捕数据只驱动头部、双手和身体姿势。要在 World 中移动或转身，请使用键盘。

| 按键 | 说明 |
| --- | --- |
| W | 前进 |
| S | 后退 |
| A | 向左平移 |
| D | 向右平移 |
| 逗号（,） | 向左转身 |
| 句号（.） | 向右转身 |

## 选择 Avatar

1. 在 Bridge 中点击「鼠标键盘控制」，按 Q 打开快捷菜单。
2. 从快捷菜单进入主菜单，然后打开 Avatars 页面。
3. 选择要使用的 Avatar，再点击更换按钮。

:::note 截图占位

:::

## 选择 World

1. 在 Bridge 中点击「鼠标键盘控制」，按 Q 打开快捷菜单。
2. 从快捷菜单进入主菜单，然后打开 Worlds 页面。
3. 选择要前往的 World，再点击进入按钮。

:::note 截图占位
VRChat 主菜单的 Worlds 页
:::

操作完成后，按 Esc 退出鼠标键盘控制，头部和双手即恢复为动捕控制。
